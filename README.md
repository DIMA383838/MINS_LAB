# Лабораторная работа №3. Антипаттерны проектирования


## Цель работы

Изучение антипаттернов проектирования и программирования, их влияния на надёжность и поддерживаемость ПО. Получение навыков выявления технического долга и его локализации.

---

## Что было сделано

В существующую информационную систему **«Автосервис»** (реализованную в ЛР №1–2 с соблюдением SOLID и паттернов проектирования) добавлена **новая функциональность** с намеренным использованием антипаттернов.

### Новая функциональность

**«Быстрый калькулятор стоимости»** 

Позволяет рассчитать примерную стоимость услуги:
- без создания записи на ремонт;
- без сохранения в историю;
- с учётом скидок/наценок (включая временную пятничную акцию 15%).

---

## Использованные антипаттерны

| Антипаттерн | Где проявился |
|-------------|----------------|
| **God Class** | `QuickPriceCalculator` — делает всё: ввод, поиск, расчёт, вывод |
| **Magic Numbers** | `0.95`, `1.20`, `0.85`, `5` |
| **Spaghetti Code** | UI, бизнес-логика и работа с репозиториями в одном методе |
| **Hardcoded Dependencies** | `new InMemoryCarRepository()` внутри класса |
| **Copy-Paste Programming** | Логика скидок скопирована из существующих стратегий |
| **Swallowing Exceptions** | `catch (Exception e) {}` без логирования |
